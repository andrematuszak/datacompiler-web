How to translate a scanned PDF

Reading time: 4 min

You have a scanned PDF — an invoice archive, a contract, a report — and you need it in another language. You paste it into a translation tool and nothing usable comes out. This guide explains why, and the workflow that actually works.

Why scanned PDFs break translation tools

A "PDF" is not one thing. A native PDF stores text as characters with font and position information, so tools can read, select and translate it directly. A scanned PDF is a stack of page images — photographs of paper. There is no text inside at all. Any tool that tries to translate it is really trying to read the image first, which is the job of OCR (optical character recognition), not translation.

Most consumer translation tools either refuse scanned PDFs outright or silently produce garbage, because they skip the OCR step or use a weak one.

The two-step workflow that works

Step 1 — OCR: image to text

Run the scan through OCR to recover the text. Quality depends heavily on the scan: straight pages, good contrast and sufficient resolution make a dramatic difference. Tables, stamps and handwriting are the usual failure points — check the OCR output before translating, because errors propagate into the translation.

Step 2 — Translate the recovered text

Once you have clean source text, translate it with a proper translation engine. If the document must keep its original look — same pages, same layout — the translated text needs to be reinserted into a rebuilt document rather than exported as a plain text file.

Keeping the layout intact

The hard part of document translation is not the language — it is the layout. Translated text is rarely the same length as the source (German expands, Chinese compresses), so naive reinsertion overflows boxes and breaks tables. A good document translation service re-typesets the text to fit the original page geometry instead of just swapping strings.

With DataCompiler, scanned documents go through both steps in one pass: the scan is read, the text is transcribed in the source language, translated into your target language, and rendered back onto page previews that keep the document's structure.
